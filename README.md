# Online Retail EDA

## 📊 Project Overview

An end-to-end Exploratory Data Analysis project using the Online Retail dataset.

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Analysis Performed

- Data cleaning
- Missing value analysis
- Duplicate detection
- Outlier analysis
- Sales statistics
- Business KPIs
- Customer segmentation
- Top countries by sales
- Top customers by sales
- Product analysis
- Monthly sales analysis
- Monthly sales growth

## 📈 Key KPIs

- Total Sales: 8,755,985
- Total Orders: 18,416
- Total Customers: 4,335
- Total Products: 3,875
- Average Order Value: 475.46
